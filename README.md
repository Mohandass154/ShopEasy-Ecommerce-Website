# 🛒 ShopEasy – E-Commerce Website

ShopEasy is a full-stack e-commerce website built using Python Flask, HTML, CSS, JavaScript, and SQLite.

## 🚀 Features

* Browse available products
* Search products by name
* Filter products by category
* Add products to the shopping cart
* Update quantities and remove items
* Place orders
* Store orders in an SQLite database

## 🛠️ Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript

## ⚙️ How to Run

1. Clone this repository:

   `git clone https://github.com/Mohandass154/ShopEasy-Ecommerce-Website.git`

2. Open the project folder:

   `cd ShopEasy-Ecommerce-Website`

3. Install the dependencies:

   `python -m pip install -r requirements.txt`

4. Start the application:

   `python app.py`

5. Open your browser at `http://127.0.0.1:5000`.

## 🎯 Project Objective

To demonstrate a basic e-commerce application with product browsing, shopping cart management, and order processing.
